# PARA说明

这个库采用 PARA 和永久笔记混合结构。

## 四类容器

- `Projects` 对应 `01项目`
  有明确结果和结束点
- `Areas` 对应 `02领域`
  需要长期维护，没有明确结束点
- `Resources` 对应 `03资源`
  作为参考资料保存
永久笔记放在 `03资源/永久笔记`
不只是资料，而是你已经吸收后的结论和判断

## 实际用法

1. 新信息先进 [[收集箱]]
2. 要推进的事情转进 `01项目`
3. 需要长期维护的事项放进 `02领域`
4. 资料类内容放到 `03资源`
5. 有长期价值的认知写进 `03资源/永久笔记`
