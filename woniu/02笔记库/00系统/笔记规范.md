# 笔记规范

## 命名规则

- 笔记标题优先使用清晰主题名，不再默认用时间戳做正式标题
- 时间戳只用于临时记录或每日笔记
- 一个主题一篇主笔记，避免同义重复

## 最低元数据

每篇正式笔记至少补这三个字段：

```yaml
type:
status:
tags: []
```

推荐补充：

```yaml
created:
updated:
aliases: []
source:
```

## 类型约定

- `fleeting`：临时记录
- `project`：项目笔记
- `area`：长期责任领域
- `resource`：资料或素材
- `permanent`：稳定认知
- `daily`：每日笔记
- `moc`：索引页

## 状态约定

- `inbox`：未整理
- `active`：正在使用
- `evergreen`：长期有效
- `on-hold`：暂停
- `done`：已完成
- `archived`：已归档

## 双链规则

- 新笔记至少链接 1 篇已有笔记
- 主题页优先链接到 `00系统` 的总览页
- 能用 `[[内部链接]]` 就不用纯文本标题

## 每周整理

1. 清理 [[收集箱]]
2. 把值得保留的内容转成正式笔记
3. 给旧笔记补 `type` 和 `tags`
4. 合并重复主题
