# 结论

链表题大多不是“背答案”，而是识别固定操作模板：虚拟头节点、双指针、分段重组、进位处理、头插法。

## 常见套路

### 1. 虚拟头节点

当题目可能删除头节点，或者返回的新链表头不稳定时，先加 `dummy` 节点最稳。

适用：

- 删除倒数第 N 个节点
- 合并或重组链表
- 构建结果链表

### 2. 快慢或前后双指针

当题目要求找到倒数位置、分割点、前驱节点时，优先考虑两个指针保持固定间隔。

适用：

- 删除倒数第 N 个节点
- 找中点
- 检测环

### 3. 分成两条链再拼接

当题目要求按条件重排节点时，不要原地硬改顺序，通常更稳的是分别维护两条子链，最后再拼起来。

适用：

- 分割链表
- 奇偶分组
- 按条件筛选节点

关键点：

- 子链尾部最后要断开，防止形成环
- 返回时跳过空头节点

### 4. 处理进位时用尾指针

链表求和这类题，本质是逐位计算和构建新链表。`dummy + tail + carry` 是最稳定的组合。

适用：

- 反向存储数字求和
- 多链表逐位运算

### 5. 正向求和时用栈或头插法

当高位在前、低位在后时，直接从头算不方便。常见做法是先压栈，再从低位弹出计算；或者递归到尾部后回溯处理。

适用：

- 正向链表求和

## 判断顺序

做链表题时可以先问自己：

1. 头节点会不会变
2. 需不需要找某个节点的前一个
3. 是修改原链表还是新建结果链表
4. 是否涉及从尾到头的计算
5. 是否要分成左右两段再拼接

## 例子

- 删除中间节点：直接覆盖当前值，再跳过下一个节点
- 分割链表：维护 `small` 和 `large` 两条链
- 删除倒数第 N 个：`dummy` 加双指针
- 链表求和：`carry + tail`
- 正向求和：栈或递归
