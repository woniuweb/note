# 结论

算法题先不要急着写代码，先判断题型，再套对应模板。你现在的每日笔记里，已经稳定出现了链表、栈队列、DP、DFS 这几类套路。

## 1. 链表题

高频模板：

- `dummy` 虚拟头节点
- 双指针找前驱或倒数位置
- 分成两条链再拼接
- `carry + tail` 处理链表求和
- 正向求和时用栈或头插法

典型场景：

- 删除中间节点
- 分割链表
- 删除倒数第 N 个节点
- 链表求和
- 正向链表求和

判断顺序：

1. 头节点会不会变
2. 需不需要找某个节点的前一个
3. 是修改原链表还是新建结果链表
4. 是否涉及从尾到头的计算

## 2. 栈和队列设计题

高频模板：

- 辅助栈保存最值
- 一个结构负责输入，一个结构负责输出
- 临时栈做有序插入
- 多个子栈分桶管理
- 按类型拆队列，再比较编号或时间戳

典型场景：

- 最小栈
- 用两个栈实现队列
- 有序栈
- SetOfStacks
- 动物收容所

关键提醒：

- 不要每次都搬运元素
- 边界条件往往比主体逻辑更容易错
- `cap = 0`、空栈、空队列要优先想清楚

## 3. DP 和 DFS

先判断题目要的是“总数/最值”还是“找路/可达”。

- 要“总数/最值” -> 更像 DP
- 要“找路/可达/路径” -> 更像 DFS/BFS

### DP

做法顺序：

1. 定义状态
2. 写状态转移
3. 处理初始值
4. 决定记忆化还是迭代滚动

例子：

- 三步问题

### DFS / 回溯

关键点：

- 越界判断
- 障碍判断
- 已访问判断
- 进入时记录路径
- 失败时回溯删除

例子：

- 迷路的机器人

## 4. 你的当前做题方式

从已有笔记看，你已经不是完全不会做题，而是容易把“具体题解”记得比“通用模板”更重。后续更高效的记法是：

1. 每道题先记题型
2. 再记核心模板
3. 最后只补最容易错的边界

这样以后复习时不会只记住某一道题，而是能迁移到同类题。
