# 结论

很多算法题先别急着写代码，先判断它属于“状态转移”还是“路径搜索”，方向定对了，代码自然会短很多。

## 两类高频问题

### 1. 状态转移问题

如果题目在问“到第 n 步有多少种方法”“当前答案依赖前几个状态”，优先考虑 DP。

典型特征：

- 问方案数、最值、可行性
- 当前结果依赖更小规模子问题
- 存在重复计算

例子：

- 三步问题

落地顺序：

1. 定义 `f(n)` 表示什么
2. 写状态转移公式
3. 处理初始值
4. 决定是记忆化搜索还是迭代滚动

### 2. 路径搜索问题

如果题目在问“能不能到终点”“找一条可行路径”，优先考虑 DFS 或 BFS。

典型特征：

- 地图、矩阵、图
- 有走过就别重复走的限制
- 需要记录路径或判断可达性

例子：

- 迷路的机器人

关键点：

- 越界判断
- 障碍判断
- 已访问判断
- 进入时记录，失败时回溯删除

## 一个实用判断法

先问题目到底要什么：

- 要“总数/最值” -> 更像 DP
- 要“找路/可达/回溯路径” -> 更像 DFS/BFS
