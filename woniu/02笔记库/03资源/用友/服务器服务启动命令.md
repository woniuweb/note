# 服务器服务启动命令

## 10.16.28.24

### Nginx（V3R6，root 用户）

```bash
/usr/local/nginxV3R6/nginx/sbin/nginx -c /usr/local/nginxV3R6/nginx/conf/nginx.conf
```

### Nginx（普通实例，yyuser 用户）

```bash
/usr/local/nginx/sbin/nginx -c /usr/local/nginx/conf/nginx.conf
```

两套 Nginx 为独立实例，分别使用各自的二进制文件与配置文件。

## Redis 服务

### Redis（6379）

```bash
/usr/local/redis/bin/redis-server
```

### Redis（6380）

```bash
/usr/local/redis-7.4.6/bin/redis-server
```

两套 Redis 均由 root 用户运行：6379 使用 `/usr/local/redis`，6380 使用 `/usr/local/redis-7.4.6`。当前仅能从进程信息确认监听端口；配置文件待确认。
